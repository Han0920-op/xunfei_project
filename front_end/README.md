# 智麦：直接与智能体对话

2026-10-28：已移除固定问卷。主导航仍只有“问智麦／我的记录”，用户直接发送文字或照片，由后端智能体结合图片观察、对话历史决定回答、补问或调用工具。

## 使用

按 [项目首页](../README.md) 安装依赖、配置讯飞／高德服务并启动后端，从同一后端地址打开 `index.html`。新页面调用 `/api/agent/chat`；仅静态启动无法获得回答，没有配置时明确报错，不用演示问答代替。

- 选照片不会自动发送；点击发送才上传本轮File。后端真实解码并调用图片模型，不能把本地图片ID或缩略图当成识别结果。
- 可直接说明“我在郑州，小麦已抽穗，今天想查天气”，不再强制先回答发生范围、生育期。
- 智能体可调用知识检索、天气及登记核对，页面显示实际进度，正文随模型真实增量显示，完成后可展开查看图片观察及查询依据。
- 从“我的记录”继续原对话、补照片复查，保留实际措施、日期和摘要；不强制选择改善／加重按钮。

发送后，文字、必要历史及本轮照片会交给后端和模型服务处理。本机继续保存记录和照片，当前无跨设备同步或主动提醒。此前图片的初步观察以历史文字延续，不作为本轮新识别；历史天气也不当作当前天气。

## 文件与兼容

| 文件                         | 职责                                                        |
| ---------------------------- | ----------------------------------------------------------- |
| `index.html`／`history.html` | 自由对话和本机记录两个入口                                  |
| `js/main.js`                 | 页面、上传、调用进度、回答与来源、跟踪操作                  |
| `js/assistant.js`            | multipart SSE客户端、有界历史、完整结果验证；无诊断问卷分支 |
| `js/store.js`                | 保留原存储键及旧资料，IndexedDB保存照片                     |
| `js/ui.js`、`css/app.css`    | 安全文字显示、图标、弹窗、响应式布局                        |
| `js/redirect.js`             | 旧链接兼容跳转                                              |

原有 `api.js`、`knowledge.js`、`pesticides.js` 暂保留兼容，新页面不加载它们。旧问卷和演示记录可查看，但选项不继续驱动诊断，也不把旧演示回复发送给模型作为真实依据。存储键 `zhimai.frontend.v1` 保留，旧 `clinicalCases` 不被清空。照片仅在确认发送时上传，本机照片不放进localStorage。

可点击“停止生成”。请求错误、流式中断、没有最终全文或 `done`、模型未配置或本地保存失败时，文字和照片保留，不保存半截回答。输出均转义显示；没有渲染任意模型HTML。

## 边界与验证

模型观察不等于确诊。天气只用真实预报，失败明确不可用；登记公告范围相符不等于当前可以施药。完整服务配置、接口和验证说明见 [对话智能体说明](../docs/conversational-agent.md)。

```sh
python front_end/tests/browser_smoke.py
python front_end/tests/backend_smoke.py
```

需要 `back_end/requirements-dev.txt` 和Chromium（默认 `/usr/bin/chromium`，可通过 `ZHIMAI_CHROMIUM` 指定）。第一项模拟SSE验证前端，第二项启动真实后端、编排与工具并显式替换付费上游；不会秘密调用真实模型。
