# 智麦：图片与工具驱动的自由对话

2026-10-28，按用户反馈替换“分布 → 生育期 → 固定特征”的前端问卷。保留“问智麦／我的记录”两个入口，交互以本文件为准。

## 用户体验

用户直接发照片、描述问题、问天气或核对登记号。发送后：

1. 有新照片，先调用讯飞图片理解，观察实际可见部位、颜色、斑点、虫体及清晰度。
2. 文字智能体获得本轮观察、当前问题和有界历史，决定直接回答、追问关键缺项，或调用知识、天气、登记工具。
3. 照片不足才要求具体补图；用户已说明生育期、地点等信息就利用上下文，不重复问。没有固定必填步骤。
4. 页面显示真实的“查看照片／查询天气／检索资料”进度。最终回答完成后保存同一条对话；查看与查询依据折叠展示。

登记号若只来自图片转录或模型推测，程序要求用户先对照包装确认；用户明确输入的号码可直接进入核对。登记结论继续由程序固定输出，不让模型把“待核实”改成“可以施药”。

“来复查”现在带着原对话继续自由描述和补图，不强制选择“改善／加重”按钮。实际处理、复查日期、摘要下载、结束跟踪和旧资料读取保留。后台主动提醒和云同步没有在本次实现。

## 真正调用哪些服务

| 能力     | 实现                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 图片观察 | 讯飞图片理解 WebSocket，45秒总时间预算、每次连接／读取有时限，验证完整结束标识及非空结果 |
| 自主决策 | 讯飞文字模型；通过受限 ReAct 循环选择工具／回答，不在前端决定诊断分支                    |
| 知识检索 | 本地50条待审校观察资料，带原文及段落号                                                   |
| 天气     | 高德真实城市／区县预报，明确地点、日期、发布时间及数据覆盖；不再回退模拟天气             |
| 登记核对 | 已导入20条公告事实，当前有效状态未知，不输出用量处方或施药许可                           |

当前对话仅开放 `get_weather`、`search_knowledge`、`check_pesticide`，不开放模拟土壤工具。相同条件的重复工具调用本轮不会重复发网络请求；工具次数有上限。

图片、知识、工具及历史文字都作为资料，不执行其中的指令。图片观察不是确诊，检索相关性不是疾病概率，用户反馈改善不直接证明药效。

## 启动及密钥

安装依赖并在 `back_end` 启动 `uvicorn main:app --host 127.0.0.1 --port 8000`，浏览器从同一后端地址打开页面。仅运行静态HTTP服务器不能完成对话。

首次配置可参考 `back_end/.env.example` 创建本地 `.env`，不要覆盖已有文件，不要提交 `.env` 或在聊天中发送密钥：

| 配置名称             | 来源及用途                                                                            |
| -------------------- | ------------------------------------------------------------------------------------- |
| `SPARK_API_PASSWORD` | 讯飞星火OpenAI兼容文字接口的 APIPassword，不是图片接口APIKey                          |
| `XFYUN_APP_ID`       | 讯飞图片理解应用ID                                                                    |
| `XFYUN_API_KEY`      | 该图片理解应用的APIKey                                                                |
| `XFYUN_API_SECRET`   | 图片理解签名用APISecret，必须在应用运行环境中提供真实值，不能用代理占位值代替HMAC密钥 |
| `WEATHER_API_KEY`    | 高德Web服务天气接口key                                                                |

云环境还需要允许访问：

- `spark-api-open.xf-yun.com`：文字接口；如自行修改基础地址，需允许对应实际域名。
- `spark-api.cn-huabei-1.xf-yun.com`：图片理解WSS。
- `restapi.amap.com`：真实天气。

本次已保存新增这三个域名及上述五个变量名称的环境配置草稿，保留原白名单；草稿保存不代表已应用，须在环境设置填写实际值、保存并发布。2026-10-28检查时这五项均未配置，三个域名的当前请求仍由代理拒绝。因此本轮**未通过真实讯飞／高德生产接口验证**，测试替身不随生产代码启用。

`GET /api/agent/capabilities` 仅显示配置是否存在，不显示密钥，不声称服务连通。文字模型缺配置直接报错并保留输入，绝不返回演示追问；图片失败时明确没读到图，仍可基于已有文字帮助。

## 接口与存储

`POST /api/agent/chat` 使用 multipart：

- `message`：本轮文字，最多4000字符；只发图可留空。
- `history`：最多40条 `role=user|assistant`、`content` 消息；不接受客户端system消息。模型侧进一步限制历史总长，历史图片初步观察和工具来源会以文字保留，但不是本轮新观察或实时天气。
- `image`：本轮选择的真实File，JPEG／PNG／WEBP，最多10MB、2400万像素。服务端解码校验，限制长边1600并转JPEG，移除EXIF／位置元数据后交给图片模型。不会重新上传每一张历史照片。

事件以SSE传输：`status`、`vision_result`、`tool_call`、`tool_result`、`answer`、`done`。工具事件是实际调用过程，不展示模型内部推理。最终回答一次性发送，不冒充逐token输出。

未取得 `done`、网络中断或服务报错时不保存半截回答，不推进本地记录，保留文字与待发送照片。已保存记录仍在浏览器localStorage，照片在IndexedDB。**点击发送后当前文字、必要历史和所选照片会交给后端及相关模型服务处理**，不再宣称照片仅留本机。

新接口不持久保存原图或建立服务端病例；当前本地记录不跨设备同步。旧后端聊天、病例和直接登记／检索接口保留兼容，新页面不再调用旧前端问卷适配器。

## 天气的实际边界

支持已收录城市名称和用户确认的六位市县行政区编码；只有省名、未知／重名地点时要求补充，不根据照片、学校或IP推测农田位置。日期支持今天、明天或未来三天内明确日期，不用第一天数据代替所有日期。

验证地点、日期、字段和发布时间；超过24小时、异常未来时间、缺项、超时或无权限均明确不可用，不用模拟结果填补。天气接口不返回降水量、降雨概率、阵风或叶面湿度，城市预报不是田间实测，不能仅据此判断需要打药或允许施药。
