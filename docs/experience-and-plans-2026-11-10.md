# 方案保存与前端体验更新

版本：`2026.11.10.experience`

## 方案保存

截图中已经生成排查要点，但没有保存方案。没有用户 Windows 后端的失败参数和日志，不能将某一种校验错误认定为该次故障的唯一原因。代码与回归测试确认：旧工具要求标题至少 6 字、步骤只能是固定字符串代码、工具参数最长 2000 字符；校验异常和存储异常都会变成笼统的 `tool_failed`。

本次变更：

- 标题接受 2–40 字；兼容带明确动作代码的步骤对象及固定中文步骤名，未知现场信息可留空。工具入口统一规范化，方案参数上限为 8000 字符。
- 模型提供的自由操作描述不直接执行；最终步骤仍由排查动作模板生成。未知动作和施药处方不通过校验。
- 格式错误返回字段反馈，并在同一请求中最多纠正一次；共用原有 140 秒时限。纠正阶段不会流出未经保存的“成功”声明。
- 区分参数错误、无有效案例、处理或存储异常。存储异常附诊断编号，并尽可能保留通过校验的排查草稿；不生成成功链接。
- 缺失或格式异常的历史来源不再阻断保存。保留身份隔离和同一轮请求去重。
- 成功回执显示步骤卡片；失败显示未保存草稿与重试入口。已存案例新增“生成排查方案”入口。
- 方案列表与详情展示步骤概览、案例背景、执行条件及来源。

## 图片提问

上传图片后展示“查看异常、病害排查、核对农药包装”；当前案例已有照片时增加“对比复查”。选择只填入输入框，不自动请求模型。空输入默认使用包含观察依据、不确定性和补图要求的提问；已输入内容不会被新上传覆盖。用户编辑后选中态同步更新。上传后收起重复拍照入口。

## 导航与视觉

一级入口为问智麦、我的记录、我的农药库、提醒与预警。提醒与预警包含：

- 提醒任务：提醒计划与检查消息。
- 天气预警：现有真实预警与明确标注的演示情景。
- 植保资讯：公开资料与来源状态（`intelligence.html?view=bulletins`）。
- 地区订阅：地区、植保与天气偏好（保留原 `intelligence.html` 地址）。

订阅是参考范围，仍与照片实际地点区分。导航沿用保留聊天页面的机制；检查消息切换也同步外层地址，返回聊天保留草稿和后台请求。

采用米白、深绿和少量麦穗金，增加轻量麦田插画、麦穗摆动、上传反馈、卡片与按钮过渡。支持系统“减少动态效果”，不使用虚假进度或模拟真实预警。

## 本机验收

1. 更新后完全重启后端，浏览器刷新；`/api/agent/capabilities` 应返回版本 `2026.11.10.experience`。
2. 打开原案例，点击“生成排查方案”。确认成功卡片可进入方案详情，刷新后仍在“我的记录 → 执行方案”中。
3. 上传图片，切换推荐问题并编辑文字；确认点击发送前没有模型请求。
4. 从“提醒与预警”切换四个二级入口，再回到问智麦；确认原有输入和照片仍保留。
5. 在手机宽度展开导航并测试关闭；在系统减少动态效果模式下不应继续播放装饰动画。

自动化使用临时数据库、真实本地 API 和浏览器，模型输出与外部服务采用测试替身；不代表用户机器上的 DeepSeek 服务已经完成实测。旧版失败消息不会因更新而自动生成方案，需要重新发送保存请求。
