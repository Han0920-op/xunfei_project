# 对话链路稳定性修复（2026-11-06）

本次针对“含图片历史的会话继续联网搜索，搜索无结果后回答格式失败”及相关边界修复。用户本机诊断编号 `0fe3553a32cf` 的服务器日志不在云环境，因此不能把云端复现当成该编号的完整故障记录。

## 已定位与修复

| 环节 | 问题 | 修复后的行为 |
| --- | --- | --- |
| 输入 | 地区订阅异步加载重新渲染整个输入区，可能干扰正在编辑的复查内容 | 只更新地区控件；发送时读取当前输入框内容 |
| 模型输出 | 有效 JSON 的字段顺序改变、完整 JSON 代码围栏、缺少可选 issue_codes 也会触发格式失败 | 标准格式继续流式显示；其他合法顺序先完整缓存并校验；仍拒绝重复字段、附加文本、多个对象与无效证据检查 |
| 格式纠正 | 历史含图片时要求证据检查，模型返回普通文本即整轮失败 | 每轮对话最多增加一次格式纠正请求，撤回错误预览，继续使用已有工具结果；认证、限流、连接错误不按格式问题重试 |
| 工具参数 | 登记号以对象形式返回时，在参数校验前就调用字符串处理，导致内部异常 | 先检查类型，错误参数转为可处理的工具结果；指定 JSON 参数支持模型返回的对象/数组，再通过原校验 |
| 搜索收尾 | 搜索失败或无结果，仍进入模型综合回答；页面笼统显示“已返回，正在整理” | 返回明确的搜索未完成/无匹配结果说明并结束；不生成诊断结论；按钮与进度恢复 |
| 综合回答失败 | 工具已执行，但末轮格式失败导致真实结果无法保存到该轮对话 | 一次纠正仍失败时，保存明确标注“未完成可靠综合回答”的实际执行回执；不保存本轮待提交的模型诊断状态 |
| 重试 | 用户重试生成新案例、轮次和照片编号，已完成但丢失的响应可能重复请求 | 相同输入在当前页面重试复用编号；服务端若已有完成记录，校验所属用户、案例、文字与照片后恢复回答，不重跑模型或工具 |
| 上游协议与耗时 | 异常 choices/delta 结构可能变成内部异常，多轮耗时累计 | 畸形流归类为受控模型协议错误；引入共享 140 秒时间预算，下一轮调用与连接/读取超时使用剩余预算 |

## 当前链路

输入与照片校验 → 所属用户/案例校验 → 检查是否有已完成的同一请求 → 构造历史与图片观察 → 模型决定回答或调用工具 → 工具白名单与参数校验 → 执行并返回真实结果 → 回答校验（必要时一次格式纠正）→ 保存案例 → 完成事件 → 前端结束等待。

工具失败、模型拒绝、流中断均有明确结果或错误。没有完整结束事件时，前端不把半截回答保存为成功，保留输入和照片。提醒仍需要点击“确认设置”，工具草案不代表已经订好提醒。

## 验证与限制

- 后端全量回归 238 项、浏览器回归 57 项。测试使用临时数据库和模型/外部工具替身，不消耗真实模型额度。
- 新增覆盖：字段乱序、完整围栏、检查不通过不泄漏正文、仅一次格式修复、搜索失败停止、已完成查询不因格式修复重跑、参数类型错误、异常上游帧、已保存请求恢复、照片变化拒绝、跨身份拒绝、前端重试编号、地区加载不替换输入框。
- 没有降低用药依据要求，也没有使用预制诊断替代真实模型。模型自检字段通过不等于农技诊断正确。
- 140 秒是调度预算，正在执行的同步工具或网络读取仍受其自身超时控制，不是严格的整轮墙钟截止时间。
- 已完成请求的恢复不等同于所有并发、跨刷新、工具执行中断场景都具备严格一次执行保证；自动入库保留已有去重保护。
- 这次未新增真实付费模型联调。此前云环境文字接口返回业务码 11200，尚无该环境成功联调证据；它与用户本机已经能部分回答的情况应分别核验。外部接口授权、额度及网络故障不能靠此补丁消除。
