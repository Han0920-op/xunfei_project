# 聊天时切换页面（2026-11-07）

截图中的窗口来自聊天页的 `beforeunload`：只要有草稿、待发送照片或进行中的请求，浏览器离开整个文档前就询问确认。原来的侧栏链接会卸载文档，直接删除保护会同时丢掉输入和正在接收的回答。

本次保留聊天文档，在同一标签页内显示其他功能页面。返回“问智麦”恢复最近正在查看的对话；“我的记录”中的“问个新问题”明确创建另一段对话，各自保留输入。

## 行为

- 从聊天切到记录、农药库、提醒、地区订阅等站内页面，不触发离站确认。
- 草稿、待发送照片、输入状态和进行中的 SSE 请求继续保留；回答完成后保存到原案例，不抢占当前页面地址。
- 返回后可查看完整回复并继续追问；出错时保留原输入、照片与重试编号。
- 浏览器前进后退恢复对应页面，手机菜单不会留下遮挡输入区的背景层。
- 管理页面离开后释放，再次进入重新读取资料；聊天页面在当前标签页存续期间保留。共享记录在读写前同步，避免不同页面使用过期副本覆盖其他案例。
- 恢复聊天时更新地区选项；后台回答完成时刷新打开的记录列表。提醒轮询只由当前显示的页面发起，避免保留的聊天页重复轮询。

## 实现范围

`navigation.js` 负责同源页面白名单、文档保留、页面地址与前进后退；管理页面和其他聊天文档通过同源 iframe 显示，沿用现有页面代码，不重复启动模型请求。独立打开管理页仍保留原有导航方式。外部链接、下载和 Ctrl/Command 点击不拦截。

站内切换不等于关闭浏览器后持续生成。实际刷新、关闭标签页、关闭浏览器或离开本站仍可能中断请求；有未保存内容时保留浏览器的离站保护。本次没有把生成任务迁移到服务端后台队列。

## 验证

全量浏览器回归 62 项通过（约 83 秒），使用临时数据库和模型替身，未调用付费模型。运行命令：`python -m unittest discover -s front_end/tests -p "*smoke.py" -q`。新增 5 项实际浏览器场景：

1. 药品核对草稿及照片 → 农药库 → 提醒 → 聊天，包含前进后退，无确认弹窗。
2. 延迟模型请求 → 记录页 → 回答完成 → 回到聊天继续追问，原轮只请求一次，后续包含历史。
3. 请求在其他页面显示期间失败 → 回到聊天 → 保留输入并重试成功。
4. 新旧两段对话分别保留草稿，侧栏返回最近对话，记录链接恢复指定对话。
5. 手机侧栏切换后返回，遮罩关闭，输入可继续编辑且没有横向溢出。

既有测试继续覆盖旧案例恢复、私有照片、农药入库、提醒确认、天气预警、流式协议和失败恢复。天气通知测试显式关闭测试订阅的夜间免打扰，避免测试结果依赖运行时刻；产品默认免打扰规则未改变。
