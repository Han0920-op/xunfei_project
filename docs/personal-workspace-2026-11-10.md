# 农药库与提醒页面视觉完善

前端资源版本：`2026.11.10.workspace`。后端接口与版本保持不变。

## 页面变化

- 农药库、提醒页采用深绿页头、暖金按钮、各自独立的 SVG 插画和轻微浮动动画。
- 实际资料驱动的概览：农药记录总数、已填写登记号、待补登记号；提醒启用、已提醒和暂停数量；消息全部、未读与已读数量。
- 农药筛选支持全部、待补登记号、有备注，并可与名称／登记号搜索组合；编辑后统计与筛选同步刷新。
- 药品卡片分开显示名称、登记号、备注、核对状态、带入聊天与编辑操作。记录数量使用“条资料”，不把记录数当成库存瓶数。
- 提醒计划与检查消息采用分段切换；新增状态筛选、未读标记与更清楚的时间排版。
- 侧栏提供资料核对说明、通知设置和天气预警／植保资讯／地区订阅入口。
- 手机下转为单列；320px 无横向溢出；系统开启减少动态效果时关闭插画动画和卡片位移。
- 所有插画随本地静态资源加载，不依赖外部图片或字体服务。

## 验证

20 项相关浏览器测试通过：个人页面、两项新增筛选与状态测试、提醒触发与工具确认、农药库带入聊天与保存、方案关联复查。

浏览器以隔离数据库和真实本地 API 验证，模型相关路径使用测试替身。没有写入用户资料或调用付费模型。另检查桌面 1440px、手机 390px、窄屏 320px 截图以及 JavaScript 语法、Prettier 格式、git diff 空白检查。

截图在 `/workspace/artifacts/zhimai-workspace/`，其中数据为测试用资料，不是实际库存或待办。
