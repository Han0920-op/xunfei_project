# 我的农药库与每日天气检查

入口：问智麦/我的记录顶部的“我的农药与提醒”，或 `personal.html`。

- 农药可新增、编辑、删除，保存名称、登记号与成分/保质期等备注。保存是用户资料，不是官方登记核验，不会自动确认可以施药。
- 智麦新增 `list_my_medicines`，按需读取当前浏览器所属农药资料，不每轮塞入整个药库。资料通过服务端HttpOnly个人凭据隔离；目前没有账号登录或跨浏览器找回，请保留浏览器凭据及服务端数据库。
- 智麦新增 `prepare_weather_check`。例如“每天早上8点，帮我查郑州天气，提醒我看看之前发黄的麦苗”，模型生成带地点/时间/事项的确认入口，进入天气页面确认后才保存。模型回答本身不代表已设置。
- 天气任务支持每日北京时间HH:MM、编辑、暂停、删除。FastAPI启动时运行后台调度，每15秒检查；每次重新查询当天高德天气，无天气也保存失败消息，不生成虚假预报或施药许可。
- 任务与队列、消息保存于 `back_end/data/local/personal.db`，不提交Git。执行前持久化队列；重启恢复待处理任务，超时租约5分钟后可重试；错过多日仅补查一次，不回放每天的旧天气。唯一结果标识避免重复生成同一次消息；修改/取消后旧任务结果不会发布。
- 提醒首版为站内消息与页面打开时的浏览器桌面通知。点击“开启本页桌面通知”授权后，保持个人页面打开；关闭页面期间结果仍存储，回来查看“检查消息”。尚未接入关闭网页后的 Web Push、短信或微信，不会声称关闭网页也能收到弹窗。
- 使用start.bat的电脑需要保持运行，关机无法在原定时间执行。后端托管到常驻服务器后可持续调度；本版不安装Windows系统服务。
- 历史对话/照片仍在原浏览器本地，不覆盖旧记录；农药库与任务属于新服务端资料。

验证：后端 `python -m unittest test_personal -v`，覆盖增删改、归属隔离、日期及地点校验、天气失败真实记录、重复扫描与暂停；现有诊断流式回归保持运行。
