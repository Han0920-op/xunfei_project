# 我的农药库与提醒

四个页面共用左侧导航：“问智麦 / 我的记录 / 我的农药库 / 提醒”。手机端通过左上角按钮展开导航。

## 设置提醒

- 在“提醒”页点击“新增提醒”：可选“普通提醒 / 天气检查”、“仅提醒一次 / 每天重复”。普通提醒不要求地点；一次性提醒必须指定未来的完整日期与时间，统一按北京时间执行，过去时间会被拒绝，不会偷偷改为次日。
- 也可以直接对智麦说“明天下午3点提醒我补拍黄叶”，或“每天早上8点查郑州天气，提醒我看看发黄的麦苗”。时间有歧义时先确认。智麦通过 `prepare_reminder` 或 `prepare_weather_check` 生成确认卡，点击“确认设置”后直接保存并提供“去提醒页查看”入口，无需再跳转填写一次。
- 只收到模型回答或草案不代表已经创建；只有服务端保存成功才显示“已设置”。同一确认卡重复请求按相同ID处理，不重复新增。支持编辑、暂停、删除。
- 原有每日天气任务默认仍为天气检查，不丢失旧任务、农药或浏览器对话记录。

## 到点怎样提醒

- 后端每3秒扫描持久化任务，先写入可恢复队列，再执行。普通提醒直接生成消息，不依赖文字模型、天气接口或城市；天气检查重新查询当天真实高德天气，失败也会保存明确提示，不编造预报或施药许可。
- 到点结果保存在“检查消息”。所有智麦页面共用5秒轮询，在聊天、我的记录或农药库页面也会出现站内提示卡和未读数，未授权桌面通知也能看到。网络、后台标签页限流或天气请求可能增加延迟，不保证秒级闹钟精度。
- 点击“知道了”或消息上的“标为已读”才持久标记已读；离线错过的未读消息，在重新打开页面时仍会提示，不在首次加载时直接忽略。
- “开启桌面通知”需要浏览器和操作系统许可，拒绝授权时站内提示仍可用。“测试提醒”仅测试当前页面提示，不创建真实任务，也不证明后端调度已执行。
- 页面另显示后端调度心跳与最近扫描时间是否有效，帮助区分“任务已保存”与“后台实际在运行”。
- 电脑、智麦后端需保持运行。关闭所有智麦网页后，当前版本不会发送 Web Push、短信或微信；后端仍可保存结果，重新打开后提示。关机时无法在原定时间执行，重启后只补查一次错过的任务，不回放多日旧天气。
- 一次性提醒触发后标为“已提醒”，不继续重复；已读或已提醒不代表农户实际完成田间检查。过期执行租约5分钟后可恢复，修改/暂停/取消后旧版本结果不发布。

## 农药和数据归属

农药库提供搜索、卡片和弹窗新增/编辑，保存名称、登记号及成分/保质期备注。`list_my_medicines` 只按需读取当前浏览器确认保存的资料，保存不等于登记核验或施药许可。

个人药品、任务、队列及已读状态保存于 `back_end/data/local/personal.db`，不提交Git。通过当前浏览器HttpOnly个人凭据隔离，没有账号登录/跨浏览器找回；请保留浏览器凭据和服务端数据库。历史对话照片仍在原浏览器本地。

## 验证

`back_end/test_personal.py` 覆盖用户隔离、增删改、一次性/每日任务、无天气服务的普通提醒、过去时间拒绝、确认幂等、已读状态、重启恢复与心跳。

`front_end/tests/reminder_smoke.py` 使用真实本机HTTP、浏览器与后台线程，验证手动设置→到点在聊天页提示（桌面未授权）、对话确认→提醒页可见、关闭页面期间生成的未读消息→重开提示。固定测试上游，不调用付费模型或天气服务。实机桌面通知仍取决于目标浏览器和操作系统权限。
