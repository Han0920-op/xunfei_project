# 用户与案例级长期记忆

当前版本使用既有浏览器身份，支持恢复码找回同一身份，不新增地块、地图或手机号登录。

## 使用入口

- “我的记录”增加“管理长期记忆与服务端案例”，进入 `memory.html`。此页可以查看、添加、更正、删除用户资料，查看案例时间线和本次确认事实、修改案例标题、删除案例以及设置恢复码。
- 新对话发送后，成功完成的文字、图片观察摘要、工具查询结果与模型回答自动作为服务端案例保存。页面标明“文字案例已保存到服务端”，但不保存原始照片。数据库保存成功后才返回 done；模型或持久化失败不伪报成功。
- 对智麦说“请记住我的常用地区是……”会生成确认卡。点击“确认记住”才写入已确认资料；同标签资料可更正，不自动把模型猜测变为事实。用户确认的资料仍不是官方或农技核验。
- 新会话按需读取用户长期资料；打开同一案例时读取该案例事实。用户提到旧问题时，`search_user_cases` 只给候选摘要，点击“是这次，继续这个案例”后才打开旧案例。没有匹配时如实说明。`get_case_history` 不能绕过确认读取其他案例详情。
- “记下我做了什么”中用户确认的实际措施，也会保存为该服务端案例的事实；结束/继续跟踪状态同步服务端。
- 同一案例的已保存对话可在新设备恢复身份后继续读取；“我的记录”展示其他设备保存的服务端案例。不将新旧咨询擅自合并。

## 来源与边界

1. 用户陈述：`user_reported`；属于历史描述，未独立核实。
2. 图片观察：独立 vision 条目，可能有误，不是原始照片或确诊。
3. 模型判断：`model_inference`，不会进入事实检索或成为新案例关联的依据。
4. 用户确认事实：`user_confirmed`，可以更正删除；不是科学有效性证明。
5. 旧记录同步：标记 `imported_user_reported` / `imported_unverified_inference`，不自动提升可信等级。

个人事实和本次事实分开，单范围最多30条；每次只携带近期有限条目，当前总数最多20条，Agent上下文还受长度限制。原始事实仍可在管理页查看。首版每个身份最多200个案例，列表默认显示最近100个，可按关键词检索更早案例；案例详情显示最近200轮。常用地区不能代替本次农田地点，历史措施不证明该措施正确或有效，历史天气不能作当前天气。

这版记忆检索为标题、用户陈述和确认事实的本地词匹配，不是向量语义记忆；检索相关性不代表病因概率。模型是否正确调用工具与解释仍需真实模型和农技评测。

## 旧记录与照片

旧浏览器数据不会自动批量上传或覆盖。管理页只对用户点击确认的旧记录同步文字；演示案例不能作为真实记忆导入，重复同步不覆盖已有案例。一次导入最多200条消息、单条文字6000字符，超限会拒绝，不静默截断。旧照片留在原设备；在原设备打开已同步案例时尽量保留已有照片引用。

新设备可读取文字和图片观察摘要，不能取回未上传的原始照片，需要时应重新拍照。原浏览器的旧照片和聊天仍受浏览器数据清理影响。

## 身份和恢复码

继承当前个人资料的 HttpOnly / SameSite 浏览器凭据。服务端通过请求凭据确定归属，不采纳模型或客户端传入的 user_id；案例、事实、检索、改删均做归属校验。不同浏览器默认是不同身份。

在长期记忆页生成恢复码，只显示一次，服务端保存SHA-256校验值。可在新设备先打开智麦，再输入恢复码找回同一份案例、确认资料、农药与任务。重置恢复码使旧码失效。恢复码相当于资料访问凭据，不要发给他人，丢失且旧浏览器凭据也丢失时本版没有短信找回。

这不是多账户登录系统。恢复操作会切换浏览器的服务端身份，不自动清除本机旧照片和记录，建议在个人设备操作；尚无共享设备登出和远程会话撤销功能。

## 存储、删除和恢复

新表位于原 `back_end/data/local/personal.db`，启动/调用时幂等建表，不替换旧库：`memory_cases`、`memory_turns`、`memory_facts`、`memory_recovery`、`memory_deleted`。备份应包含该数据库。

删除案例会删除服务端该案例的对话和事实，并移除当前设备对应本地记录；仅保留防止旧请求重新写入的编号墓碑。其他设备已缓存的旧文字/照片不会被远程擦除。已经删除的案例ID不能被迟到的模型响应重新创建。

删除一条确认资料不会篡改旧聊天文字，旧聊天仍标注其历史来源。用户可以另行删除整个案例。

## 验证

`back_end/test_memory.py` 覆盖成功保存、失败不保存、请求幂等、用户隔离、跨新会话读取、更正/删除、确认前不写入、模型推断不参与匹配、案例关联确认、恢复码及重置、旧记录导入和删除后拒绝迟到请求。

`front_end/tests/memory_smoke.py` 用真实本机HTTP及浏览器、模型替身，验证“对话准备→确认资料→新会话引用”“候选案例确认→恢复旧问题”“恢复码→新浏览器取回案例”“手动同步旧文字→删除”。没有用付费接口结果作为本轮验收依据。
