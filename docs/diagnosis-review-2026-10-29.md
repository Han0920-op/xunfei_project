# 2026-10-29：冬小麦生育期错误排查

## 现象与证据边界

用户截图显示：第一张金黄麦穗照片被解释为“结合当前10月下旬，正常成熟收获阶段”；随后的种植计划回答复述该结论；第二张幼苗状、叶片黄化照片仍被解释为成熟衰老并建议收获。

截图证明最终回答有错误，但折叠的图片观察和工具记录未展开。没有用户本机localStorage、原始图片文件、图片服务原始响应或当次工具事件，不能断言是图片模型首先判断错，也不能断言当次没有调用知识工具。新接口没有服务端病例/对话日志，仓库无法还原该次实际请求。

## 代码中确认的薄弱点

| 环节       | 原有行为                                                             | 风险                                                                                               |
| ---------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 时间与照片 | system注入当前北京时间；图片预处理去掉EXIF，接口没有单独拍摄日期字段 | 模型把对话日期当拍摄日期，编造季节解释                                                             |
| 图片       | 每轮新照片都会独立调用图片理解，不重复上传旧图；观察为自由文本       | 不是简单“没调用图片工具”，但缺少形态/生育期证据约束                                                |
| 模型       | 更换SPARK_MODEL只影响文字服务；图片服务仍是`imagev3`                 | 升级文字模型并不等于升级图片识别                                                                   |
| 历史       | 前端把上一轮最终回答作为assistant历史继续传入                        | 错误结论反复出现，可能影响新照片解读；具体影响程度需原始调用记录确认                               |
| 知识       | 50条待审校的症状/环境因素资料，检索由模型自主选择                    | 没有地区生育期日历；检索相似黄化词不能证明自然成熟；只有提示词要求检索，没有程序强制每个结论有来源 |
| 最终输出   | 自然语言回答直接发出                                                 | 没有时间、形态、历史冲突及“未见病虫≠健康”的最后检查                                                |

因此，确认的是决策证据管理和复核不足。图片识别、模型农业常识、当轮是否查询资料各自的贡献尚不能定量归因。天气预报不提供该田块生育期，增加天气调用不能直接解决该问题。

## 应有的回答方向

1. 金黄麦穗：描述成熟外观，不确认冬春性、拍摄地点/月份、整体健康或已满足收获条件。若涉及当前冬小麦安排，先确认拍摄时间/地区。
2. 种植计划追问：不能以模型上一轮说“成熟”就跳过秋播计划。先核实用户真正要规划的田块和种植季。
3. 幼苗状黄叶：按新图重新分析，明确黄化现象及视野局限；不能由“没看到虫”排除病虫害，也不能由“叶黄”推导成熟。病虫害、营养、水分、低温、药害等仅是待核实方向，不是图片确诊。
4. 河南及黄淮海常规露地冬小麦通常秋播、次年晚春初夏收获；作为明显矛盾的常识线索即可，不能把它硬套到所有地区、旧照或特殊种植。

## 本地修正与限制

已增强独立图片观察和时间/田块边界，去除图片决策上下文中的历史助手最终结论。最初增加第二次完整回答复核；响应速度优化后改为同轮结构化自检及流式正文，前置检查不合格则不输出正文，流中断则撤回预览。详见[当前实现](conversational-agent.md)。页面和导出摘要保留原始图片观察与自检状态。

这仍是同一文字模型自检，不是确定性的农艺专家系统。相关测试使用明确的模型替身，验证时间/形态约束、历史隔离、检查不合格不能输出以及中断保护，不证明真实X2.6或图片服务一定能识别正确。

下一步最有价值的验证是：取得这两轮“查看与查询依据”中的图片观察/工具结果，定位首个偏差；用有拍摄日期、地区及农技标注的幼苗/拔节/有穗照片建立真实评测集；再引入带来源、适用区域和审校状态的生育期知识。无需恢复固定问卷，也不应为了调用工具而调用天气。
